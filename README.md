# Cineverse - Movie Explorer

Cineverse is a modern web application that helps you explore and discover movies with ease. Built with a sleek interface, responsive design, and OMDB API integration, Cineverse provides detailed information about movies, including plot summaries, release dates, genres, and more.

---

## Features

- **Movie Search**: Find movies by title and explore their details.
- **Detailed Information**:
  - Movie Poster
  - Plot Summary
  - Release Date
  - Language
  - Genre
  - IMDB Rating
  - Box Office Collection
  - Cast and Crew
- **Responsive Design**: Optimized for all screen sizes.
- **Interactive Animations**: Engaging effects and smooth transitions.
